Persona Pengguna

Profil pengguna utama yang menjadi fokus pengembangan EzyDraw

R

Rumi

Usia: 24 Semester: 3 Prodi: Sains Data

Tujuan Utama

Menyelesaikan presentasi dan mockup proyek dengan cepat dan visual menarik, menggunakan Canva sebagai shortcut sebelum disempurnakan (jika perlu) di software profesional.

Masalah Utama

Membutuhkan alat desain yang lebih cepat dan mudah daripada software profesional (Photoshop), namun masih bisa diintegrasikan dengan workflow desain yang lebih detail dan tanpa perlu bergantung pada aset premium berbayar.

Temuan Utama

Hasil wawancara dan observasi pengguna

1

Pengguna Hybrid yang Berorientasi Kualitas

Responden menggunakan Canva hanya sebagai "pintasan" untuk kemudahan awal, namun masih melibatkan Photoshop dalam workflow-nya untuk melihat hasil akhir.

2

Kebutuhan akan Efisiensi

Pemilihan Canva didorong oleh kebutuhan akan kemudahan, intuitif, dan template siap pakai untuk presentasi.

3

Fokus pada Platform Desktop

Responden menganggap ukuran layar Mobile terlalu kecil dan lebih memilih menggunakan Desktop (Laptop/Browser).

4

Masalah Kualitas Akhir

Responden menghindari menggunakan Canva untuk kebutuhan cetak dan print dalam resolusi tinggi.

Mendesain aplikasi desain grafis berbasis Desktop (EzyDraw) yang membantu Mahasiswa Hybrid seperti Rumi untuk mencapai kualitas output profesional, kinerja stabil offline, dan akses ke semua aset premium secara ekonomis, sehingga mereka tidak perlu berkompromi antara kecepatan, kualitas, dan biaya.

Solusi Final Terpilih

Implementasi fitur utama EzyDraw

Arsitektur Offline-First Berbasis Desktop

Merancang EzyDraw sebagai aplikasi desktop (native) yang mengutamakan Mode Offline dan mengalihkan proses berat (seperti rendering dan pengeditan) sepenuhnya ke sumber daya lokal (CPU/RAM).

Mode Offline AutoSave Mode Lite

Model Bisnis Buy-Once, Get All Premium

Menerapkan model Sekali Bayar dengan Harga Merakyat yang memberikan akses penuh ke Semua Aset dan fitur premium (seperti Smart Remove Object dan Background Remover) secara permanen.

One-time Payment All Assets Included No Subscription

Ekosistem Shortcut dan Kualitas Terjamin

Menyediakan Template Bawaan yang Bervariasi dan fungsionalitas Konversi ke Berbagai Format File sekaligus mendukung Plugin/Ekstensi Pihak Ketiga.

Varied Templates Multi-Format Export Plugin Support
